# Публичный сайт 777xsz

База перед переработкой: 402fb8e5515dc740581370c1ef1107bbc1f8ccd0.

## Выявленные проблемы

Главная загружала три конкурирующих CSS и четыре JS, плюс встроенный обработчик формы. Версии ресурсов различались между маршрутами. Старые генераторы способны перезаписать актуальный сайт данными прежнего проекта. Анимация ранее зависела от CSS и нескольких разных контроллеров. WebKit-тесты запускались после публикации в main.

## Новая структура

* assets/public-site.css: единая система оформления, сетки, формы, каталог, портфолио, мобильная навигация.
* assets/public-site.js: интерфейс, формы WhatsApp, ROI, поиск курсов, настройка движения.
* assets/pricing-777xsz.js: отдельный расчёт сметы. Существующие тарифы не меняются.
* GIF-ресурсы v17: кадровая анимация; неподвижные кадры для отключённого движения.
* Старые CSS/JS оставлены на диске для совместимости с историческими материалами, но не загружаются коммерческими страницами.
* Читалки курсов, книг и инструкций не переписаны: у них отдельные функции закладок, прогресса и режима чтения.

## Проверка и публикация

Статические проверки SEO, ссылок, структуры и единого набора ресурсов. Браузерные проверки Chromium и WebKit на 320, 375, 390, 768 и 1440 px; калькуляторы, формы, меню, поиск, анимация и отключение движения. Реальный Safari на iPhone требует отдельной проверки владельцем. Основная ветка не изменяется до успешной проверки кандидата.

## Editorial pass

All 13 commercial service pages reviewed for intent, visible scope, pricing, handover, objections and metadata. Main page uses problem-first guidance, no client portfolio. Browser QA captures the first screen for each route and reports internal overflow. Educational lesson text remains a separate editorial scope.
