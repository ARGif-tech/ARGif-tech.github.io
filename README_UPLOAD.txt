ОБНОВЛЕНИЕ AR WORKS

1. Распакуйте архив.
2. Загрузите файлы из папки сайта в корень существующего репозитория GitHub Pages с заменой одноимённых файлов.
3. Сохраните изменения (Commit changes) и дождитесь завершения публикации GitHub Pages.
4. Проверьте сайт и при необходимости обновите страницу с очисткой кеша.

Загружайте отдельные файлы, а не ZIP-архив и не родительскую папку. Имена уже правильные: без суффикса (1).

Не удаляйте остальные файлы репозитория, включая dezinsektsiya.html, cafe-restaurants.html, sitemap.xml и CNAME, если они есть. Эти страницы и настройки домена не были предоставлены.

Обновлены шесть предоставленных страниц: логотип, значок вкладки и изображение предпросмотра ссылки. На главной обновлён блок с фирменным знаком и услугами. В архиве также есть растровые изображения по прежним именам для совместимости с оставшимися страницами.

Изменения подготовлены для загрузки; на действующем сайте они пока не опубликованы.
